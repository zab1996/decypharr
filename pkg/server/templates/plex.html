Plex

Connect decypharr to Plex to prewarm the next episode's cache while a real viewer is watching. decypharr polls Plex's own /status/sessions API for genuine active playback — once a session crosses 70% through an episode, the next episode (if tracked by decypharr) gets its first ~20% fetched into cache ahead of time, so it starts up faster if the viewer continues.
